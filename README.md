# 记忆书房 · The Memory Study

一个可以取书、翻页、查看高清影像的个人影像书架，包含地点地球仪和保存在当前浏览器的草稿功能。

## 本地运行

使用 Node.js 22 或更新版本和 pnpm 11.25.0。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

打开 http://127.0.0.1:3217/ 。

## 构建与部署

```sh
pnpm build
```

将生成的 `out/` 目录部署到静态网站服务的根路径。请通过 HTTP 访问，不能直接双击 HTML 文件。源码包与静态展示包是同一版本的两种运行方式。

需要读者新建的草稿与书架排列仅保存在读者自己的浏览器中。本仓库未附带浏览器数据。

代码和影像未授予开放再分发许可；第三方组件、字体和地图按各自许可证使用，见 `THIRD_PARTY/`。
